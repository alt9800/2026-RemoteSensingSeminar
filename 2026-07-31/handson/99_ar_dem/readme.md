# 99_ar_dem：DEMをARで見る（アイディア・参考）

ハンズオンの範囲外ですが、Terrain RGBデコードの理解を試す応用として面白いので、アイディアと構成だけ残しておきます。

## 卓上に地形模型を置くAR

Terrain RGBタイルをデコードし、Three.js / A-Frameの `PlaneGeometry` の頂点Z値に標高を与えると、机の上に地形模型を置くARが作れます。

```
タイルPNG取得 → canvasでRGB読み出し → 標高値の2次元配列
  → PlaneGeometry（セグメント数 = ピクセル数）の頂点変位
  → A-Frameのシーンに配置（マーカーAR or 平面検出）
```

- 屋内で完結し、GPS・方位精度に依存しないのが利点
- 第3回のA-Frame環境（`ar-threex-location-only.js` の読み込み順など）がそのまま使えます
- 1タイル（256x256）で65,536頂点。スマホなら1〜数タイル分に間引くのが現実的です

## 実地形に重ねる位置情報AR

「いま見ている山の稜線にDEM由来の等高線を重ねる」方向は、第3回で経験した方位ずれ・測位誤差がそのまま精度に効きます。数十mの位置ずれが視覚的に露骨に出るため、補正コントローラ（第3回の実装）が前提になります。挑戦する場合は模型ARで地形メッシュ生成を先に固めてからを勧めます。
