# 01_terrain3d：MapLibre terrainによる3D表示

第5回の検証ビューア（hillshade）を3D地形ビューアに発展させます。完成版は同梱の `index.html` です。

## 手順

1. `index.html` 冒頭の設定ブロックを自分のデータに合わせて書き換える

```js
const TERRAIN_URL = "pmtiles://../terrain.pmtiles";  // 自分の成果物のパス
const CENTER = [131.256, 33.983];   // データの中心付近
const ZOOM = 14;
const MINZOOM = 8;    // pmtiles show で確認した実際の値に合わせる
const MAXZOOM = 14;   // 同上
```

`MINZOOM` / `MAXZOOM` は必ず `pmtiles show` の値と一致させてください。実データより低い `minzoom` を書くと、そのズームにはタイルが存在しないため初期表示が空になります。

2. ブラウザで開き、以下を確認する

- pitchを倒す（右ドラッグまたは右上コントロール）と地形が立体になる
- 垂直誇張スライダーで起伏の強さが変わる
- hillshadeのON/OFFで陰影の有無が切り替わる
- クリックした地点の標高が表示される

## 標高の検算

クリックで表示される標高値を、第5回の `gdalinfo -stats dem_cog.tif` の最小・最大値や、地理院地図の標高表示と突き合わせてください。

- 値が -10000 m 前後：NoData領域（データの被覆外）をクリックしています。1mメッシュ由来のデータは実測範囲が狭く、範囲外がこの値になります
- 値が全体に数十mずれる：楕円体高とジオイド高の混同（第5回参照）

## デコード式（クリック標高の実装）

```
標高 = -10000 + (R * 65536 + G * 256 + B) * 0.1
```

`index.html` ではタイルPNGをcanvasに描き、クリック位置のピクセルのRGBを読んでこの式を適用しています。MapLibreが内部でやっていることと同じです。
