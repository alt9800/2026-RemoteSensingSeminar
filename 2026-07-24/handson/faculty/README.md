## 3. ブラウジングタイム（Part 3・約5分）の台本

一緒に見るサイトと見せる順序：

1. G空間情報センター：「VIRTUAL SHIZUOKA」で検索 → LAS配布ページ → タイル分割と容量感を見せる
2. 基盤地図情報DLサイト：数値標高モデルの選択画面 → 10m/5m/1mの整備範囲の差を地図で見せる
3. GSI 1mメッシュの公開ページ（07のURL） → 整備状況図（マゼンタ/青の塗り分け地図）で山口県内の整備範囲を確認
4. 時間があれば：mapterhorn.com のviewer → 「完成形」として一瞬見せて第6回への引きにする

回線が不安定な場合に備え、各ページのスクリーンショットをスライドの手元資料に保存しておくこと。

## 4. 想定トラブルと即答集

| 症状 | 即答 |
|---|---|
| Windowsで `rio: command not found` | OSGeo4W ShellではなくpipのScriptsにPATHが必要。`python -m rio_cogeo` / venvのactivate忘れを確認 |
| `gdal_calc.py: not found`（macOS brew） | `gdal_calc.py` がPATH外のことがある。`python3 -m osgeo_utils.gdal_calc` で代替 |
| rgbifyがメモリエラー | 対象範囲を半分にクリップして続行させる。「範囲を絞って試す」は本編の教えと整合 |
| hillshadeが真っ黒 | (1) zoomがminzoom未満 (2) encoding指定ミス (3) mbtilesのY軸反転。06のクリック標高で切り分け：値が出るならタイルは正常で表示設定の問題 |
| クリック標高が-10000近辺 | RGBがすべて0 = NoData領域。データ範囲内か確認 |
| 標高が実際の値と数十mずれる | ジオイド高の混入（スライドPart 3参照）。1m/点群データで起きやすい |
| file://で開いてしまった | ローカルサーバー必須。`python3 -m http.server` へ誘導 |
| 地理院淡色タイルが出ない | 会場ネットワークの制限の可能性。ビューアはベースなしでもhillshadeは出るので続行可能 |
