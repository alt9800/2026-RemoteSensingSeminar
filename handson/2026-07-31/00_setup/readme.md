# 00_setup：前回成果物の確認と配布データ

## 1. 前回成果物の確認

第5回で作成したファイルを確認します。

```sh
pmtiles show terrain.pmtiles
```

以下を確認してください。

- `minzoom` / `maxzoom`：タイル生成時に指定したズーム範囲と一致しているか
- `bounds`：対象範囲（山口県内）の経緯度になっているか

`bounds` が `-180,-85,180,85`（全世界）になっている場合は、第5回の `05_tiles_pmtiles` に記載のメタデータ修正を行ってから進んでください。タイル自体は正しく格納されているため、作り直しは不要です。

## 3. ローカルサーバー

このディレクトリの親（`handson/`）をHTTPで配信した状態で各ステップに進みます。

```sh
python3 -m http.server 8000
# または
npx http-server -p 8000
```
