# 03. deck.glで点群を地図に重ねる

Potreeは点群単体を見るには優れていますが、背景地図がありません。ここではdeck.glのPointCloudLayerを使い、OSMタイルの地図の上に点群を重ねて表示します。

完成版アプリは [app/index.html](./app/) にあります。HTMLファイル1つで完結し、読み込む外部スクリプトはdeck.glのCDNバンドル1つだけです。

## 使い方

1. `app/index.html` と同じ階層に、01で書き出したLASファイルを置く
2. `index.html` 内の2箇所を自分のデータに合わせて書き換える
   - `LAS_FILE`：LASファイル名
   - `SCAN_ORIGIN`：スキャン地点の経緯度 `[経度, 緯度]`（Scaniverseの位置情報表示、またはGoogleマップ等で確認）
3. ローカルWebサーバー経由で開く（`file://` 直接は不可）

```sh
cd app
python3 -m http.server 8000
# → http://localhost:8000/
```

## このコードで最も重要な点：座標系の設定

**前提**

- ScaniverseのLAS出力は**UTM投影座標系**です。座標値はメートル単位の大きな絶対値（たとえばX=500000, Y=3720000程度）になっています
- deck.glの `COORDINATE_SYSTEM.METER_OFFSETS` は、`coordinateOrigin` に指定した経緯度を原点として、そこからの**メートルオフセット**として座標値を解釈します

**何が起きるか**

UTM座標をそのまま渡すと「原点から500km東、3720km北」と解釈されてしまい、点群は画面のはるか外に描画されて何も見えません。

**対処**

UTM絶対座標から基準値を差し引いて、スキャン地点付近を原点とする相対座標に変換します。このサンプルではLASヘッダのoffset値を差し引いています。

```js
// LASヘッダのoffsetをUTM原点として差し引く
points[i].position[0] -= las.xOffset;
points[i].position[1] -= las.yOffset;
points[i].position[2] -= las.zOffset;
```

差し引く値は点群のバウンディングボックスの中心付近を使います。`pdal info` コマンドや、CloudCompareのプロパティ表示で確認できる値です。CloudCompareで「シフトを保持したまま」保存していれば、ヘッダのoffset値がおおむねこの用途に使えます。

## なぜloaders.glを使わないのか

deck.glのエコシステムにはLASファイル用のローダーライブラリ（loaders.gl）が存在します。ただしCDN環境では、deck.gl内蔵の画像ローダーとの競合が起きることがあるため、この教材ではDataViewによるシンプルな自前パーサーを採用しています。

なお、loaders.glのLASLoaderを使う場合でも、**LASファイルに記録されたCRS情報（EPSGコード等）は解釈されません**。座標値をそのまま数値として読み出すだけなので、上記の座標変換は同様に必要です。

## LAS 1.2バイナリ構造の要点

自前パーサーが読んでいるのは以下のフィールドです（すべてリトルエンディアン）。

| バイト位置 | 内容 |
|-----------|------|
| 0–3 | シグネチャ `LASF` |
| 96 | 点レコードの開始オフセット（uint32） |
| 104 | Point Data Format（uint8）。2または3ならRGBあり |
| 105 | 点レコード長（uint16） |
| 107 | 点数（uint32） |
| 131– | X/Y/Zスケール（float64 ×3） |
| 155– | X/Y/Zオフセット（float64 ×3） |

各点の座標は `int32のraw値 × scale + offset` で実座標に復元します。RGBはPoint Format 2なら各レコードの20バイト目、Format 3なら28バイト目から16bit×3で格納されており、上位8bitを取り出して0–255に変換しています。

外部サービスやライブラリをブラックボックスにせず、バイナリの中身まで自分の目で確認する。第1回のprotobuf/MVTと同じ姿勢です。

## つまずきポイント

| 症状 | 確認すること |
|------|-------------|
| 何も表示されない | ブラウザのコンソールで `First pt:` の座標を確認。数十万〜数百万の値ならoffset差し引きが効いていない |
| 点が灰色一色 | Point Format 0/1（RGBなし）。Scaniverseのエクスポート設定を確認 |
| 地図と点群の位置がずれる | `SCAN_ORIGIN` の経緯度が実際のスキャン地点と合っているか確認 |
| ページが固まる | 点数過多。01のサブサンプリングに戻る（数十万点目安） |
| fetchが失敗する | `file://` で開いている。http-server等を経由する |
