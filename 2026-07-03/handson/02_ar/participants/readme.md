# ハンズオン② 操作手順（受講者用）

## 準備

- 屋外に出て、周囲の安全を確認する。歩きながらの操作はしない。
- iPhone は Safari、Android は Chrome で開く。

## 手順

1. 講師が案内するURL（`.../02_ar/app/`）を開く。
2. 「開始」を押す。iPhone では「動作と方向」「カメラ」「位置情報」の許可を求められるので、すべて許可する。
3. カメラ映像が表示され、画面上部に現在地（GPS）が出る。
4. その場でゆっくり一回転する。周囲の観測ポイントのラベルとブロックが、方位に合わせて見える。
5. 端末を近づけたり離れたりして、距離に応じてオブジェクトの大きさが変わることを確認する。

## 見てほしいところ

- ラベルの色。NDVI の値で色が変わる（水域は青、植生が濃いほど緑）。
- 圃場区画が半透明のブロックとして立ち上がって見えること。
- 端末を回したとき、オブジェクトが実際の方角に留まって見えるか。

## うまくいかないとき

- オブジェクトが出ない：屋外で、画面上部にGPSの座標が出ているか確認する。屋内では位置が定まらない。
- 向きが合わない：端末を空中で8の字に数回振る（方位センサーの補正）。
- カメラが出ない：URLが `https://` で始まっているか、カメラの許可をしたかを確認する。
