# ハンズオン② 操作手順（受講者用）

## 準備

- 屋外に出て、周囲の安全を確認する。歩きながらの操作はしない。
- iPhoneはSafari、AndroidはChromeで開く。

## 手順

1. 講師が案内するURL（`.../02_ar/app/`）を開く。
2. 「開始」を押す。iPhoneでは「動作と方向」「カメラ」「位置情報」の許可を求められる
   ので、すべて許可する。
3. カメラ映像が表示され、画面上部に現在地（GPS）・方位・表示件数が出る。
4. その場でゆっくり一回転する。周囲の農地区画の輪郭線とラベルが、方位に合わせて見える。

## 画面の見方

- 画面右下の小さい地図（ミニマップ）：現在地と、向いている方角が矢印付きのアイコンで
  表示される。タップすると地図が全画面表示に切り替わる。もう一度タップ（または「閉じる」
  ボタン）で元の大きさに戻る。
- 画面左下の「方位補正」：輪郭線が実際の方角と明らかにずれて見える場合、タップして
  展開し、`+`/`-`のボタンで見た目が合うように調整できる。

## 見てほしいところ

- 輪郭線の位置。カメラ映像上で、実際の農地の境界とおおよそ重なって見えるか。
- 端末を回したとき、輪郭線が実際の方角に留まって見えるか。
- ミニマップ上のビーコンと矢印が、実際に自分がいる場所・向いている方向と一致するか。

## うまくいかないとき

- 何も表示されない：屋外で、画面上部にGPSの座標が出ているか確認する。屋内では
  位置が定まらない。「表示: 0件」の横に距離が出ている場合、範囲外にいることを示す。
- 向きが実際とずれる：まず「方位補正」で見た目を調整する。改善しない場合は、端末を
  空中で8の字に数回振ってから試す（方位センサーの補正）。
- カメラが出ない：URLが`https://`で始まっているか、カメラの許可をしたかを確認する。
