# ハンズオン① 操作手順（受講者用）

## 手順

1. 講師が案内するURLを、スマホのブラウザ（iPhoneは Safari、Androidは Chrome）で開く。
2. 「センサーを開始」を押す。iPhoneでは許可を求められるので「許可」を選ぶ。
3. 緯度・経度・精度が表示されることを確認する。
4. 端末を水平に持ち、その場でゆっくり一回転する。方位ダイヤルの針が常に北を指すか、方位の数値（度）が変化するかを見る。
5. 端末を前後・左右に傾け、beta（前後）と gamma（左右）の値が変わることを確認する。

## 見てほしいところ

- 画面下の「取得方式」の表示。iPhone と Android で違う名前が出る。
- 針が指す北が、実際の北（や地図アプリの方位）と合っているか。
- 端末を横向きにすると方位がずれないか。

## うまくいかないとき

- 値が出ない：URLが `https://` で始まっているか確認する。
- iPhoneで許可ダイアログが出ない：`設定 > Safari > モーションと画面の向きのアクセス` を確認し、ページを再読み込みする。
- 針が北を指さない：端末を空中で8の字に何度か振る（方位センサーの補正）。
